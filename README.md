# SentinelMX — Setup & Run Guide

AI-Powered Email Threat Detection, GeoLocation & Forensic Intelligence
Platform. Built for Smart India Hackathon 2026 (Problem Statement SIH26106).

```
sentinelmx/
├── backend/
│   ├── main.py              FastAPI app + /api/v1/analyze-email endpoint
│   ├── models.py             Pydantic request/response schemas
│   ├── pii_redaction.py      SSN / card / phone / bank-account redaction
│   ├── geo_engine.py         Received: header parsing + geolocation
│   ├── claude_analyzer.py    Anthropic Claude structured-analysis call
│   ├── evidence_locker.py    SHA-256 chain-of-custody hashing
│   ├── graph_connector.py    Neo4j AuraDB campaign-graph connector
│   └── requirements.txt
├── frontend/
│   └── index.html            Single-file dark-mode SOC dashboard
└── README.md                 (this file)
```

## 1. Prerequisites

- Python 3.10+
- An Anthropic API key ([console.anthropic.com](https://console.anthropic.com))
- (Optional) A free Neo4j AuraDB instance, if you want the campaign-graph
  feature live rather than skipped

## 2. Install dependencies

```bash
cd sentinelmx/backend
python -m venv venv

# macOS/Linux
source venv/bin/activate
# Windows (PowerShell)
venv\Scripts\Activate.ps1

pip install -r requirements.txt
```

## 3. Set environment variables

**macOS/Linux:**
```bash
export ANTHROPIC_API_KEY="sk-ant-your-key-here"

# Optional — only if you're wiring up the graph connector
export NEO4J_URI="neo4j+s://xxxxxxxx.databases.neo4j.io"
export NEO4J_USER="neo4j"
export NEO4J_PASSWORD="your-password"
```

**Windows (PowerShell):**
```powershell
$env:ANTHROPIC_API_KEY="sk-ant-your-key-here"
$env:NEO4J_URI="neo4j+s://xxxxxxxx.databases.neo4j.io"
$env:NEO4J_USER="neo4j"
$env:NEO4J_PASSWORD="your-password"
```

Prefer a `.env` file instead? Create one in `backend/` with the same
`KEY=value` lines — `python-dotenv` is already in `requirements.txt`; add
`from dotenv import load_dotenv; load_dotenv()` at the top of `main.py` to
pick it up automatically.

If `NEO4J_URI` is left unset, the app runs fine — every response's
`graph_ingest.attempted` will simply read `false` and the field is skipped.

## 4. Run the backend

```bash
# from inside sentinelmx/backend/
uvicorn main:app --reload --port 8000
```

You should see Uvicorn come up on `http://localhost:8000`. Sanity-check it:

```bash
curl http://localhost:8000/api/v1/health
```

Interactive API docs (auto-generated by FastAPI) are at
`http://localhost:8000/docs`.

## 5. Open the dashboard

Just open `frontend/index.html` directly in a browser (double-click it, or
`open frontend/index.html` / `start frontend/index.html`). The dashboard's
top bar has an editable backend URL field, pre-filled with
`http://localhost:8000` — it will show a live green "backend online"
indicator once the server is reachable.

Click **"Load sample header set"** to drop in a pre-built phishing sample,
then **"Analyze Email"** to run the full pipeline end-to-end.

## 6. What's simulated vs. real for the hackathon build

- **Geolocation:** `geo_engine.py` uses a small built-in lookup table so the
  demo has zero external dependencies and deterministic output. Swapping in
  real MaxMind GeoLite2 data is a single function change — see the comment
  block at the top of `geolocate_ip()` for the exact `geoip2` snippet. You'll
  need a free MaxMind license key to download `GeoLite2-City.mmdb`.
- **Claude model:** the code targets `claude-sonnet-4-6` (Anthropic's current
  general-purpose model at time of writing). Check
  [the models overview](https://docs.claude.com/en/docs/about-claude/models/overview)
  if you want to pin a specific dated snapshot for reproducibility in your
  hackathon report.
- **Threat feed persistence:** stored in-memory in `main.py` for the demo —
  restart the server and it clears. Swap `_THREAT_FEED` for a real table
  before any real deployment.
- **CORS:** `main.py` currently allows every origin (`allow_origins=["*"]`)
  so the dashboard "just works" regardless of how you're serving the HTML
  file. Restrict this to your actual dashboard's origin before deploying
  anywhere beyond your own machine.
